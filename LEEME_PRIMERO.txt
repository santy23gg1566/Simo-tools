SIMO HUB TOOLS 3.0 — HTML + WEB + APK
==================================

QUE CAMBIA
- Nuevo nombre y rediseño completo, adaptable a PC, tablet y celular.
- Nuevas herramientas: horario, tareas/exámenes, plan semanal, notas, calificaciones, tarjetas, enfoque, calculadora.
- Juegos: quiz, memoria y 2048.
- 9 paletas de color, claro/oscuro/automático, fuente, animaciones, vista compacta.
- Acceso local con contraseña, guardado cifrado, respaldo e importación.
- Toasts discretos en vez de ventanas molestas.
- Botón de instalación web (PWA) cuando el navegador lo permite.

EDITAR DESDE BLOC DE NOTAS
Abre www/index.html en el Bloc de notas. Guarda los cambios.
Todo el CSS y el JavaScript de la interfaz están en este único archivo.

ACTUALIZAR EL APK EN GITHUB
1. Abre https://github.com/santy23gg1566/Simo-tools
2. Entra en www/index.html y pulsa Edit (lápiz) para reemplazar su contenido.
   Para la actualización 3.0, SUBE TAMBIÉN todos los otros archivos y carpetas
   de este ZIP, pues el nombre, los iconos, la PWA y el workflow también cambian.
3. Asegúrate de tener .github/workflows/android-apk.yml en tu repositorio.
4. Guarda con Commit changes.
5. En Actions abre "Compilar Simo Hub Tools APK".
6. Cuando salga verde, ve a Releases y descarga Simo-Hub-Tools.apk DIRECTAMENTE
   si aparece la publicación. Si Github deniega los permisos de Releases, usa Artifacts.
   Enlace estable después de la primera ejecución: 
   https://github.com/santy23gg1566/Simo-tools/releases/download/hub-latest/Simo-Hub-Tools.apk
7. También puedes ir a Actions > Summary > Artifacts y descargar el ZIP
   SIMO-HUB-TOOLS-APK, que ahora contiene Simo-Hub-Tools.apk.

PUBLICAR COMO WEB / INSTALAR CON BOTON
En Netlify puedes subir SOLO la carpeta www (su contenido debe quedar como
raíz del sitio). En GitHub Pages puedes publicar los mismos archivos.
Cuando visitas la web publicada con HTTPS, abre Configuración > Instalar.
En Chrome Android se puede abrir una ventana nativa de instalación en un toque
si el navegador considera instalable la PWA. La confirmación del sistema
sigue siendo obligatoria. En iPhone puedes usar Compartir > Añadir a inicio.

SOBRE LAS ALERTAS AL INSTALAR
Los avisos de Android / Play Protect por instalar APK fuera de tiendas NO
se pueden quitar desde HTML ni desde GitHub Actions. El APK DEBUG anterior
puede tener una firma distinta tras cada compilación.

PARA ACTUALIZAR ENCIMA SIN REINSTALAR
Necesitas una clave de firma privada estable, siempre la misma:
- SIMO_KEYSTORE_B64
- SIMO_KEYSTORE_PASSWORD
- SIMO_KEY_ALIAS
- SIMO_KEY_PASSWORD
Son Secrets de GitHub Actions; consulta GUIA_FIRMA_Y_ACTUALIZACIONES.txt.
Tras instalar por primera vez la APK firmada release, las posteriores versiones
con igual packageId y clave, y mayor versionCode, podrán actualizarse encima.
Conservamos el packageId "com.simo.tools2027" del APK anterior. AUN ASI,
si el APK anterior está firmado con otra clave, tendrás que EXPORTAR DATOS,
DESINSTALAR EL ANTERIOR E INSTALAR EL NUEVO una vez. El nuevo sistema usa
un formato diferente y NO migra automáticamente los datos antiguos.

ACCESO Y DATOS
Login local, NO sincronizado ni recuperable desde servidores.
Las cuentas antiguas de SIMÓ TOOLS 2027 NO se importan automáticamente.
El respaldo nuevo exporta JSON sin cifrar: mantenlo privado.
Autologin conserva una clave en el dispositivo, no apropiado para secretos.
No hay notificaciones push ni funcionamiento del temporizador en segundo plano.

Nunca compartas tu contraseña ni una clave de firma privada por chat o GitHub.
